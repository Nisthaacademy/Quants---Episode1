# Nistha Academy | Quantitative Aptitude — Episode 1

**Build speed. Improve accuracy. Strengthen your calculation fundamentals.**

Welcome to **Episode 1** of Nistha Academy's Quantitative Aptitude learning series. This episode focuses on the essential calculation reference tables that students can practise regularly before moving on to faster mental-maths techniques and exam-style problem solving.

## Episode 1: Calculation Fundamentals

### Learning objectives

By using the reference sheets in this repository, students can work toward:

- Recalling multiplication tables quickly (1–30).
- Recognising perfect squares and cubes (1–30).
- Becoming familiar with reciprocals (1–20) and their decimal values.
- Improving calculation fluency for Quantitative Aptitude and Data Interpretation.

## Suggested daily practice

1. **5 minutes:** Revise multiplication tables.
2. **5 minutes:** Test your memory of squares and cubes.
3. **5 minutes:** Practise common reciprocals and their decimal equivalents.
4. **5 minutes:** Solve quick mental-calculation questions without a calculator.

**Practice tip:** Test yourself in random order, not only from 1 to 30. Aim for both speed and accuracy.
